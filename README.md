### [Reviu](https://github.com/fysaio/pr-reviewer) &nbsp; `Personal Project`

An AI pull-request reviewer that understands repository context, not just the diff. GitHub webhooks trigger a Celery/Redis pipeline; relevant source files are retrieved through vector search before Gemini reviews the change. Posts findings through GitHub Checks and inline comments. Includes a dashboard for per-repository settings and an evaluation harness measuring precision, recall, and F1.

### [Plant Disease Detector](https://thymosian-plant-disease-detector-streamlit-app-4xnfqg.streamlit.app) &nbsp; `ML Project`

Upload a crop-leaf image and classify it with a fine-tuned ResNet18 model trained for 15 disease classes. Below a 75% confidence threshold, the app returns “Unknown” rather than forcing a prediction. Includes a Streamlit interface and CLI workflow.
